# Slime Soccer

A retro arcade 2D physics-based soccer game featuring bouncy slimes, realistic ball physics, and intelligent AI opponents.

## Features
- Two-player local multiplayer and single-player vs AI modes
- Physics-based movement, jumping, and ball mechanics
- Intelligent AI opponent with strategic positioning
- Anti-camping mechanics to keep gameplay dynamic
- Customizable match duration (1-8 minutes)
- Retro arcade visual style

## How to Play
1. Open `index.html` in a modern web browser
2. Select game mode (Single Player or Multiplayer)
3. Choose match duration
4. Use arrow keys to move, jump, and grab the ball
5. Score goals to win!

## Controls
- **Left/Right Arrow**: Move slime
- **Up Arrow**: Jump
- **Down Arrow / Space**: Grab/Release ball

Enjoy!
